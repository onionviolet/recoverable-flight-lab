# Contributing questions and ideas

Public contributions will open when this repository is made public. Until then, repository access is required.

Use the **Project question** or **Proposed idea** form under Issues. Name the relevant module or board record, state the question or proposal, and include supporting sources where available. GitHub requires an account to submit. Avoid including private board backups or personal information.

Maintainers review submissions, request clarification as needed, and record whether each proposal is accepted for exploration, deferred, or declined, with a reason. Accepted material is added to the canonical board through a reviewed repository change. Acceptance for exploration does not establish engineering validity or approval for construction.

The website stores edits in each visitor's browser. Issues are the shared discussion channel; local card edits do not update another visitor's board. Comments on an existing issue keep discussion with its original proposal.
